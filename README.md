# Marktkompass – isolierte Intraday-Testseite

Dieses Repository ist ausschließlich für eine getrennte Online-Testseite vorgesehen.

- Keine historischen ACWI-/VIX-Rohdaten.
- Keine Berechnungslogik und keine Worker-Schreibzugriffe.
- Die Seite liest den zuletzt veröffentlichten Status und fragt den Intraday-Kandidaten ausschließlich lesend ab.
- Ein gelesener Intraday-Kandidat wird hier nicht bestätigt, gespeichert oder neu berechnet.

Die Testseite ist keine Produktivversion und kein Kauf- oder Verkaufssignal.
